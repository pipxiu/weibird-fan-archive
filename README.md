# Wei-Planet | 韦宇宙

一个关于韦礼安的个人歌迷档案，收藏歌曲、音乐故事、演出记忆与歌迷手账。使用 HTML、CSS 和少量 JavaScript 制作，可直接发布到 GitHub Pages。

## 本地预览

直接用浏览器打开 `index.html` 即可。页面不需要安装依赖，也不需要构建步骤。

## 发布到 GitHub Pages

仓库已设置为从 `main` 分支的根目录发布。提交到 `main` 后，GitHub Pages 会自动更新。

网站地址：[https://pipxiu.github.io/weibird-fan-archive/](https://pipxiu.github.io/weibird-fan-archive/)

如需检查设置，打开仓库 **Settings → Pages**，确认来源为 **Deploy from a branch**，分支为 `main`，目录为 `/(root)`。

## 更新内容时常改的位置

- 首页与各栏目文案、歌曲列表、时间线和示例手账都在 `index.html`。
- 颜色、字号、间距和手机布局都在 `styles.css`。
- 歌曲筛选、收藏按钮和手机导航都在 `script.js`。
- 收藏信息存在访客自己的浏览器中。换设备或清除浏览器数据后不会同步。

当前演出区和手账内容含有模板文字。请把示例替换成自己的记录，并在添加演出时核对官方公告。网站中的唱片、票根和照片均为 CSS 图形，没有使用韦礼安的肖像或未经确认的现场照片。网站是个人歌迷整理项目，非官方。
